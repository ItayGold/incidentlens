# Roadmap

This roadmap is directional. It does not promise dates, availability, or a future
open-source release of private implementation.

| Milestone | Status | Intended outcome |
| --- | --- | --- |
| Public foundation | Present in this repository | Vision, boundaries, static page, and synthetic handoff |
| Workflow discovery | Proposed | Validate security/operations handoff needs using safe examples |
| Output contract | Proposed | Review provenance, uncertainty, and timeline representation |
| Private prototype | Proposed | Evaluate an investigation workflow on authorized synthetic inputs |
| Trust readiness | Proposed | Define and verify controls before accepting real incident data |
| Limited evaluation | Proposed | Consider scoped evaluation only after readiness criteria are met |

## Readiness principles

Useful evidence presentation comes before automation claims. Privacy and access
controls come before real-data collection. Any evaluation should distinguish
unsupported hypotheses from verified observations and measure whether a handoff
actually helps responders.

Feature status will be updated when implementation and review justify it.
